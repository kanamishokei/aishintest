愛真幼稚園 ホームページ・リニューアル版

開き方:
1. index.html をブラウザで開いてください。
2. 各メニューからページ間を移動できます。

含まれる主な画面:
- TOP
- 園について
- 園の生活
- あいしんモーメント（カテゴリー絞り込み）
- 投稿詳細
- お知らせ
- 資料・書類ダウンロード
- 入園案内
- 子育て支援
- アクセス
- 公式サイト原文コンテンツ（official-content.js）

注意:
- 写真は現行公式サイトから取得した公開画像を使用しています。
- 文章は現行公式サイトの公開情報をもとに整理した初期版です。詳細ページは要約ではなく、公式サイトの本文・項目・料金・時間・注意事項をできるだけそのまま掲載する構成にしています。
- CMS、問い合わせ送信、PDF実ファイル、保護者ログインは未接続です。
